# GreenTechnologyMarketplace
java web application for buying and selling eco-friendly products with product, order, review, and admin management.
We developed a web project, Green Technology Marketplace, in Java. The idea of this project is to create a platform where people can discover and purchase eco-friendly products and vendors can add and manage their products.

The project has multiple features for customers, vendors and admins. The users can signup and login, vendors can add products and admin can approve or reject products before they are displayed in the marketplace. The customer can browse the products, order and give ratings and reviews.
